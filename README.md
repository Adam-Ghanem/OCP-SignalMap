# OCP SignalMap

A browser-based tool for visualizing and analyzing mobile network coverage measurements.

## Features

- CSV import and validation
- Interactive coverage mapping
- Signal quality statistics and filters
- Report and image export

## Running the application

Open the published web application or serve `index.html` using a local HTTP server. CSV processing runs in the browser; do not upload confidential network measurements to a publicly hosted application without authorization and a data-handling review.

## Technologies

JavaScript, Leaflet, Leaflet.heat, Papa Parse, html2canvas and jsPDF.
